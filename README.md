# Web3Inferno

Web3Inferno enables real-time blockchain network analysis through automated smart contract execution on a decentralized node/agent.

Web3Inferno is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Web3Inferno enables real-time blockchain network
- analysis through automated smart contract
- execution on a decentralized node/agent

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Inferno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
